# Lar São Vicente de Paulo — prévia institucional

`npm install` e `npm run dev`; `npm run build` gera dist para Vercel/Netlify. Os dois vídeos e imagens estão locais. As imagens de estrutura foram recortadas da referência conceitual, não são fotografias verificadas do Lar. Antes de publicar: validar autorização, fotos reais, serviços, contatos oficiais, situação do projeto e canais de doação; liberar indexação em robots.txt e criar sitemap com domínio definitivo. Nenhum pagamento ou formulário falso é implementado.
